คู่มือทำการ์ดผีเสื้อ AR (ต้นแบบ)
=================================

ไฟล์ในโฟลเดอร์นี้
- index.html : หน้าเว็บ AR สำหรับเปิดกล้องและแสดงผีเสื้อ 3 มิติ
- card.jpg   : ภาพการ์ดผีเสื้อของคุณ ใช้เป็นภาพเป้าหมาย (image target)

ขั้นตอนที่ 1: สร้างไฟล์เป้าหมายสำหรับ AR
1. เปิด https://hiukim.github.io/mind-ar-js-doc/tools/compile/
2. ลากไฟล์ card.jpg จากโฟลเดอร์นี้ลงในหน้า Image Targets Compiler
3. กด Start และรอให้ระบบวิเคราะห์ภาพจนเสร็จ
4. กด Download เพื่อดาวน์โหลดไฟล์ .mind (มักชื่อ targets.mind)
5. นำไฟล์ targets.mind มาใส่ไว้ในโฟลเดอร์เดียวกับ index.html

ขั้นตอนที่ 2: ทดสอบบนเครื่อง
- ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ ไม่ใช่ดับเบิลคลิก index.html
- หากมี Python ให้เปิด Terminal ในโฟลเดอร์นี้ แล้วรัน: python -m http.server 8000
- เปิด http://localhost:8000 บนคอมพิวเตอร์เพื่อทดสอบ
- การใช้กล้องบนมือถือจากเว็บไซต์จริงต้องเผยแพร่ผ่าน HTTPS

ขั้นตอนที่ 3: ทำเป็นลิงก์ให้สแกนด้วยมือถือ
- อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวม targets.mind) ไปยังโฮสต์เว็บแบบ static ที่รองรับ HTTPS เช่น GitHub Pages หรือ Netlify
- เปิด URL ที่ได้บนมือถือ กดเริ่มสแกน และอนุญาตการใช้กล้อง
- ส่องกล้องไปที่การ์ดใบเดิมที่ใช้สร้าง targets.mind

หมายเหตุ
- นี่เป็นโปรเจกต์ต้นแบบที่เตรียมโค้ด AR และภาพการ์ดไว้แล้ว แต่ยังต้องสร้าง targets.mind และนำขึ้นโฮสต์ HTTPS ก่อนจึงจะสแกนใช้งานจริงได้
- โมเดลผีเสื้อ GLB โหลดจาก 3DAssets.dev (CC0 ตามหน้าระบุสินทรัพย์) ต้องใช้อินเทอร์เน็ตขณะโหลดโมเดล
- การหมุนเป็นการหมุนโมเดลทั้งตัว ไม่ใช่การกระพือปีก
- หากพิมพ์การ์ดใหม่ ควรพิมพ์จากภาพเดิมโดยไม่ครอปหรือเปลี่ยนสี/สัดส่วน เพื่อให้ติดตามภาพได้ดี
